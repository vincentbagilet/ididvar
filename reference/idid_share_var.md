# Share of the variance removed by partialling out

Computes the share of the variance of a variable that is removed by
partialling out the controls.

## Usage

``` r
idid_share_var(
  reg,
  var_to_partial,
  var_interest = var_to_partial,
  partial_iv = TRUE,
  ...
)
```

## Arguments

- reg:

  A regression object (or its control form, returned by `idid_to_cf`).

- var_to_partial:

  A string. The name of the variable for which to compute a partialled
  out version (the outcome or a regressor).

- var_interest:

  A vector string. The name of the variables of interest (coefficient
  names, eg `treat:post`, or variable names, eg `x` for `fit_x`).

- partial_iv:

  A boolean. If TRUE, partials out the part of the endogenous variables
  that are not explained by the instruments. If the regression is not an
  IV (or not generated by
  [`AER::ivreg`](https://rdrr.io/pkg/AER/man/ivreg.html) or
  [`fixest::feols`](https://lrberge.github.io/fixest/reference/feols.html)
  with an instrumented part), the value of `partial_iv` has no impact on
  the outcome of the function.

- ...:

  Not used.

## Value

A numeric. The share of the variance of `var_to_partial` removed by
partialling out.

## Details

The variable is partialled out with `idid_partial_out`. The share of the
variance removed is the R² of the regression of the variable on the
fixed effects and controls. For weighted regressions, observations are
weighted by the regression weights.

## Examples

``` r
reg_ex <- ggplot2::txhousing |>
  lm(formula = log(sales) ~ median + listings + city + as.factor(date))

idid_share_var(reg_ex, "median")
#> [1] 0.884074
```
