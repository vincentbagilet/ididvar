# Compute Identifying Variation Weights

Compute regression weights describing the amount of variation used for
identification.

## Usage

``` r
idid_weights(reg, var_interest, partial_iv = TRUE, tol = 1e-07, ...)
```

## Arguments

- reg:

  A regression object (or its control form, returned by `idid_to_cf`).

- var_interest:

  A vector string. The name of the variables of interest (coefficient
  names, eg `treat:post`, or variable names, eg `x` for `fit_x`).

- partial_iv:

  A boolean. If TRUE, partials out the part of the endogenous variables
  that are not explained by the instruments. If the regression is not an
  IV (or not generated by
  [`AER::ivreg`](https://rdrr.io/pkg/AER/man/ivreg.html) or
  [`fixest::feols`](https://lrberge.github.io/fixest/reference/feols.html)
  with an instrumented part), the value of `partial_iv` has no impact on
  the outcome of the function.

- tol:

  A numeric. Passed to the `qr` function. The tolerance for detecting
  linear dependencies in the columns of x_partialled.

- ...:

  Not used.

## Value

A numeric vector of the identifying variation weights for each
observation.

## Details

The weights correspond to the normalized leverage of each observation
for the variables of interest after partialling out all controls.

The partialled out version of the variables of interest is computed with
`idid_partial_out`, on the control form of the regression (see
`idid_to_cf`). For weighted regressions (and GLMs), observations are
weighted by the regression weights.

## Examples

``` r
reg_ex_lm <- ggplot2::txhousing |>
  lm(formula = log(sales) ~ median + listings + city + as.factor(date))

idid_weights(reg_ex_lm, "median") |>
 head()
#> [1] 8.693583e-05 9.188898e-06 1.504876e-05 1.274063e-05 3.686616e-06
#> [6] 1.076007e-05
```
